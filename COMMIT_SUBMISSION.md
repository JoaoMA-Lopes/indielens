# Commit Your Submission to GitHub

## Quick Commands

Run these commands in order:

```bash
# Go to repo root
cd C:\Users\joao\indielens

# Add all essential files
git add LICENSE
git add README.md
git add JUDGES_SETUP.md
git add SUBMISSION_CHECKLIST.md
git add SUBMISSION_STRATEGY.md
git add HACKATHON_SUBMISSION_NOTES.md
git add FINAL_SUBMISSION_READY.md
git add YOUR_SUBMISSION_IS_READY.md
git add DEPLOYMENT_OPTIONS.md
git add QUICK_DEPLOY_GITHUB_PAGES.md

# Add demo and modified files
git add web/demo.html
git add cpp/ConsoleApplication1/ConsoleApplication1/*.cpp
git add cpp/ConsoleApplication1/ConsoleApplication1/*.h
git add cpp/config.example.json

# Commit
git commit -m "Add Chrome AI integration and hackathon submission materials"

# Push
git push origin chrome-2025
```

## After Committing

1. Go to GitHub repository
2. Enable GitHub Pages (Settings > Pages)
3. Deploy demo.html
4. Get your public URL!

1. Record your video
